How this pass was run — keywords → Trends (5yr + 12mo) → Shopping → TikTok → Meta Ads Library, all checked live

13 sustainability products were researched live on Aug 10, 2026 across four parallel research passes (3-4 products each). For each: correct English keyword → Google Trends chart checked at both 5-year and 12-month ranges, live, plus its interest-by-region breakdown and related/rising queries → Google Shopping search (live pricing/ratings, doubling as a competition check) → TikTok video search (live) → Meta Ads Library (live active-ad check, since Meta retired the standalone Audience Insights tool in 2024).

The lowest-scoring 3 of 13 — Natural Cleaning Products (3/10, saturated by CPG brands + noisy Trends data), Canvas Tote Bags (4/10, a single viral fashion moment already faded), and Travel Utensil Set (4/10, thinnest data of the set on every channel) — were dropped to keep this report to the top 10. One honest limitation: the browser tool used has no way to export screenshots as image files, so pictures aren't embeddable here — each "Live source views" block links to the exact same live query instead.

Methodology & limitations

13 sustainability products from Shopify's "Sustainability" niche list were researched live on Aug 10, 2026, following the same checklist used for the Car Accessories report: correct English keywords, demand reviewed at both 5-year and 12-month Trends windows plus interest-by-region and related/rising queries, Google Shopping, TikTok, and the Meta Ads Library, all opened live across four parallel research passes. The lowest-scoring 3 were dropped to keep this to the top 10. Honest gaps, flagged rather than papered over:

  • Google Keyword Planner requires an authenticated Google Ads account, unavailable in this session. Search-volume figures throughout are Trends-relative-index readings and marketplace-review proxies, not Planner-grade numbers.
  • Meta Audience Insights (the standalone tool) was discontinued by Meta in 2024. The Meta Ads Library was used as the live substitute — match quality varied widely: Compostable Plates and Organic Cotton Bedding returned 100% genuine on-product ads, while Sustainable Activewear and Insulated Water Bottles were roughly half genuine, and Reusable Metal Straws returned essentially no dedicated advertisers at all (~3 results).
  • The Solid Shampoo Bars spike is a specific, flagged concern: the Trends breakout timing lines up almost exactly with one advertiser's (Humby Organics) campaign launch date, suggesting the "demand spike" may be substantially ad-driven rather than organic — reported directly rather than smoothed into a clean growth story.
  • Screenshots were captured and reviewed live for every chart, listing, and search shown — but the browser tool used has no way to export them as image files, so they can't be embedded in this document. Each "Live source views" block links to the exact same query so you can reopen the identical live view at any time.
