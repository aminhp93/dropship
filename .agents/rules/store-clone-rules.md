# STORE CLONE & COPYRIGHT COMPLIANCE RULES

## 1. Strictly Forbidden Image Practices
- **NO Competitor Photo Scraping for Live Use**: NEVER scrape, copy, crop, or edit product photos, lifestyle images, or banners from competitor websites for live store upload.
- **NO Watermark Editing**: Removing, blurring, or overlaying logos on copyrighted competitor photos is strictly prohibited due to legal DMCA risks and source obfuscation.

## 2. Mandatory Image Workflow for Store Building
- **Default to Placeholders**: When building or cloning a store, use neutral AI-generated placeholders or designated placeholder graphics for product cards and banners.
- **Allowed Competitor Extraction**: Extract ONLY raw structure, feature lists, pricing models, category naming, and copy/facts.
- **User Image Supply**: Require explicit supplier photos (from AliExpress, CJ Dropshipping, 1688) or custom user photos before attaching real product images to store listings.

## 3. Mandatory 4-Step Store Clone Operating Protocol
1. **Analyze Structure & Copy**: Extract structure, collection names, copy facts (without claims that lack verification e.g. "Airbag Compatible").
2. **Flag Gaps & Unfulfillable Items**: List explicitly what AI cannot fulfill (e.g. real supplier product photos, verified compliance claims, domain purchase).
3. **Build Non-Dependent Infrastructure**: Create collections, menus, policies, draft products using placeholders and verified data.
4. **Final Assembly & Verification**: Attach real supplier assets only after user provides and approves them.
